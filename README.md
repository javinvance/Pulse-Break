# Pulse Break

Pulse Break is a mobile app designed to help users manage stress in real time through quick check-ins, personalized break recommendations, and guided reflection.

## Features
- Stress level check-ins
- Smart break recommendations
- Guided reflection prompts
- Check-in history tracking
- Stress trend visualization

## Tech Stack
- React Native (Expo)
- Expo Router
- AsyncStorage

## Purpose
Built to promote mental awareness and productivity by helping users pause, reset, and refocus throughout their day.

## Status
MVP complete. Actively improving features and user experience.
